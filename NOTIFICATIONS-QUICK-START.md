# Notifications Quick Start Guide

## What's New? 🔔

Your IntelliCare Support chat system now has **real-time notifications** for admin and superadmin users!

## Quick Overview

- ✅ **Browser Notifications**: Desktop alerts for new messages
- ✅ **Unread Badges**: Visual indicators everywhere
- ✅ **Smart Tracking**: Separate counts for direct messages and channels
- ✅ **Easy Control**: Toggle notifications on/off with one click
- ✅ **Auto-Clear**: Unread counts clear when you view conversations

## How to Enable Notifications

### Step 1: Navigate to Chat
Click on **Chat** in the sidebar menu

### Step 2: Enable Notifications
Click the 🔔 **bell icon** in the chat header

### Step 3: Grant Permission
When prompted, click **Allow** to enable browser notifications

**That's it!** You're now set up to receive notifications.

## Understanding the Visual Indicators

### 1. **Sidebar Menu Badge**
```
Chat (3)  ← Total unread messages
```
Red badge shows total unread messages across all conversations

### 2. **Tab Badges**
```
Direct (2)    Channels (1)
```
Shows number of conversations with unread messages in each tab

### 3. **User/Channel List**
```
John Smith          (2)  ← Unread from John
#general-chat       (5)  ← Unread in general-chat
```
Individual unread counts next to each conversation

### 4. **Page Title**
```
(3) IntelliCare Support
```
Browser tab title shows total unread count

### 5. **Bell Icon**
- 🔔 (solid) = Notifications enabled
- 🔕 (with slash) = Notifications disabled
- Red badge on bell = Total unread count

## Notification Types

### Direct Messages
When an admin sends you a direct message:
- 📧 Browser notification: "New message from John Smith"
- 🔊 Sound/vibration (based on your OS settings)
- 📊 Unread count increments

### Channel Messages
When someone posts in a channel:
- 📧 Browser notification: "John Smith in #general-chat"
- 🔊 Sound/vibration
- 📊 Unread count increments

### @Mentions
When someone mentions you:
- 📧 **High-priority** browser notification
- ⏳ Stays visible until you click it
- 🔔 Special mention indicator

## When You'll Get Notified

### Page is Hidden/Background
✅ Browser notification appears
✅ Desktop alert with sound
✅ Unread count increments

### Page is Visible/Active
✅ Toast notification (small popup)
✅ Unread count increments
❌ No browser notification (to avoid duplicates)

## Clearing Unread Messages

### Automatic Clearing
- Click on any conversation → unread count clears automatically
- Click on a browser notification → jumps to conversation and clears

### Manual Review
Check the unread badges to see which conversations need attention

## Tips & Tricks

### 💡 Stay Updated
Keep the Chat page open in a browser tab for real-time updates

### 💡 Do Not Disturb
Disable notifications temporarily by clicking the bell icon

### 💡 Sound Control
Adjust notification sounds in your OS notification settings

### 💡 Multiple Devices
Enable notifications on all devices you use

### 💡 Check Regularly
Even with notifications, check Chat regularly for important updates

## Troubleshooting

### Notifications Not Working?

**Check 1: Permission**
- Is the bell icon solid (🔔)?
- If not, click it and grant permission

**Check 2: Browser Settings**
- Open browser settings
- Check site permissions for notifications
- Ensure notifications aren't blocked

**Check 3: OS Settings**
- Check your operating system notification settings
- Ensure browser notifications are allowed

**Check 4: Connection**
- Look for green dot in chat header
- If red, reconnect to the internet

### Still Having Issues?
1. Try refreshing the page
2. Clear browser cache
3. Try a different browser
4. Contact your system administrator
